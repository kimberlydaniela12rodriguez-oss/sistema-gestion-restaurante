#Sistema de Gestión Comercial para Restaurantes

Aplicación de escritorio desarrollada en Python para la automatización, cálculo de pedidos y administración de comandas en restaurantes. El sistema calcula dinámicamente impuestos y almacena la información de forma estructurada.

##  Características Principales
* **Carga de Datos Completa (CRUD):** Registro, modificación y eliminación de pedidos en tiempo real.
* **Cálculo Automatizado:** Procesa automáticamente el IVA (16%), la comisión por servicio (10%) y el monto neto total de cada comensal.
* **Módulo de Reportes:** Generación de un ticket digital detallado con el resumen de la cuenta listo para el cliente.
* **Persistencia de Datos:** Conexión e integración con base de datos SQL para almacenar el historial de ventas.

##  Tecnologías Utilizadas
* **Lenguaje:** Python 3
* **Interfaz Gráfica:** Tkinter / TTK
* **Base de Datos:** SQL (Módulo de Carga)
